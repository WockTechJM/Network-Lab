
# Corporate Network Lab

## Project Overview

This project is a simulated corporate network built using Cisco Packet Tracer.

The purpose of this project is to apply networking concepts through hands-on configuration, testing, and troubleshooting.

The network includes two departments: Office and IT, with centralized network services, wired and wireless connectivity, and network security configurations.

## Tools Used

- Cisco Packet Tracer
- Cisco IOS CLI
- Visual Studio Code
- Git and GitHub

## Project Goals

- Configure VLANs and network segmentation.
- Implement IPv4 addressing and routing.
- Configure DHCP and DNS services.
- Implement network security using ACLs and port security.
- Configure SSH for remote device management.
- Explore Syslog and Spanning Tree Protocol.
- Configure wireless connectivity.
- Introduce firewall and ISP connectivity.
